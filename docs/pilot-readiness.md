# Pilot readiness

## Ready for controlled testing

- Role-specific authentication and onboarding
- Artist upload/campaign workflow
- DJ and matatu participation with controlled track access
- Verification, posted-ledger earnings, notifications and Admin review
- RLS, private audio, audit records and a health endpoint

## Not production-complete

- No live M-Pesa collection or payouts; mock money paths default off
- Listener recognition is a labelled demo and stores no raw audio
- Legal pages require Kenyan counsel and a rights/takedown process
- No offline service worker, deliberately avoiding unsafe private-media caching
- Alerts, support ownership, incident response and recovery drills require operator configuration

A pilot should use invited accounts and test funds only after the staging role/RLS matrix passes. Public launch requires live payments, final legal review, production monitoring and named incident/rollback owners.
